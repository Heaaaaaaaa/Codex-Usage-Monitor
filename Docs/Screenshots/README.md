# Public Screenshots

The images in this folder are rendered from the app's real SwiftUI views using only synthetic data generated by `Tools/MakeDemoFixture.py`. They contain no personal Codex logs, project paths, chat names, or account data.

Generate a fresh fixture relative to the current date:

```bash
python3 Tools/MakeDemoFixture.py \
  --out /private/tmp/CodexUsageMonitorDemo \
  --replace
```

For deterministic parser tests, provide an explicit UTC reference time:

```bash
python3 Tools/MakeDemoFixture.py \
  --out /private/tmp/CodexUsageMonitorDemo \
  --now 2026-07-11T12:00:00Z \
  --replace
```

Run `make render-preview` on macOS to render Overview in light, dark, and compact layouts, plus Activity, Breakdown, and every Settings page. PNG and JPEG files are written to `build/design-previews`. The renderer uses an isolated preferences domain and the generated fixture, never the user's data. Native view rendering excludes the cursor and window decoration.

Use `overview-dark.jpeg` for `dashboard.jpeg` and `rates-dark.jpeg` for `pricing-rates.jpeg`. The committed images show complete content viewports without cropping or retouching.

Before committing, inspect both images at their original size. The full popover must be present, the pointer must be outside the captured pixels, and no text field may have selected text or a focus highlight. Export the final files as complete baseline JPEGs so repository and browser previews render the entire frame consistently.
